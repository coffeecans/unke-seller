# UNKE Seller Notebook

Мобильный веб-сервис для учета персональных продаж продавца за день.

## Локальный запуск

```bash
python server.py
```

Откройте: `http://localhost:8000`

## Запуск по ссылке из GitHub (публичный URL)

Проект настроен для деплоя напрямую из GitHub на Render через `render.yaml`.

1. Загрузите этот проект в свой GitHub-репозиторий.
2. Зайдите на https://render.com и нажмите **New + → Blueprint**.
3. Подключите ваш GitHub-репозиторий.
4. Render автоматически прочитает `render.yaml`, создаст веб-сервис и выдаст публичную ссылку вида:
   - `https://<your-service>.onrender.com`
5. Откройте эту ссылку с телефона — приложение будет доступно по URL.

> Важно: на бесплатном тарифе Render сервис может "засыпать" и просыпаться несколько секунд при первом открытии.

## Что умеет

- Корзина с поиском по каталогу и добавлением товаров.
- Подсчет общей суммы, скидка в процентах, заметка и фото к продаже.
- Список продаж за выбранный день, поиск и редактирование записи.
- Экспорт всех продаж в Excel-совместимый `.xls`.
- Обновление каталога с `https://unke.store/catalog` (с fallback на локальный каталог, если парсинг недоступен).
