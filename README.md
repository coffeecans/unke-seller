# UNKE Seller Notebook

Мобильный веб-сервис для учета персональных продаж продавца за день.

## Запуск

```bash
python server.py
```

Откройте: `http://localhost:8000`

## Что умеет

- Корзина с поиском по каталогу и добавлением товаров.
- Подсчет общей суммы, скидка в процентах, заметка и фото к продаже.
- Список продаж за выбранный день, поиск и редактирование записи.
- Экспорт всех продаж в Excel-совместимый `.xls`.
- Обновление каталога с `https://unke.store/catalog` (с fallback на локальный каталог, если парсинг недоступен).
